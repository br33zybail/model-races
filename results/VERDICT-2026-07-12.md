## C. What the shapes taught us

1. **Single-shot code-fix and log-triage are commoditized** (nearly everyone 1.0)
   → route to cheapest/fastest: gemini-flash-lite, haiku, tool-fast. Never pay
   heavy-tier for these.
2. **Audit-with-named-specifics is the great separator** → gpt-oss family,
   GLM-5.2, sol at 0.667; everyone else 0. Fable (agentic) was the only perfect
   score. Route audits: reasoner-free first, Fable/Opus when it matters.
3. **Contract-following INVERTS the size ladder**: small obedient models
   (gpt-oss-20b, qwen, gemini, glm-4.7-flash) beat the big reasoners (GLM-5.2,
   DeepSeek, MiMo — and Fable) at delivering an exact stated interface.
   Route stub/scaffold/schema-conformance work to `tool-fast`.
4. **Twin transfer is real**: both local models track their cloud twins' shape
   profiles. Benchmarks on cloud twins now predict local behavior → race in the
   cloud for cents, deploy the winner locally for free.
5. **Head ≠ worker.** GPT-OSS-120B is the best free worker and a failed head.
   Orchestration demands artifact discipline (files, not prose) — currently only
   CC+Fable has it out of the box; omp heads need it injected via skill prompt.

## F. Post-hoc validation probes (same day, after skill-tree fold-in)

Two fresh, uncoached `claude -p` sessions (CC+Fable, global CLAUDE.md + skills
only) verified the folded rubric actually drives behavior:

- **Small probe** (12-line triage + 1 stub + tiny audit): ZERO gateway calls —
  session cited the playbook and correctly judged delegation overhead > work.
  It also nailed the exact `allow(key)->bool` contract Fable had failed twice
  in the race, i.e. the F4 lesson lands via the skill. Restraint verified.
- **Long-horizon probe** (220-line triage, 3 contract modules, dual independent
  reviews, audit): 1 head + 4 workers, 19 gateway calls, $0.08 —
  tool-coder drafted the modules, reasoner-free + grok-shared reviewed as
  independent families (grok caught a real monotonic-clock-outside-lock race
  that gpt-oss missed; confirmed and fixed pre-ship), tool-fast took
  mechanical work, Fable kept the audit and found all 3 planted issues.
  All 3 modules passed execution grading; triage 220/220 (semantic).
  Fan-out verified. It even self-dispatched code-simplifier per CLAUDE.md.

**Rule of thumb now measured twice: 1 head + 3–5 workers on long-horizon work,
scaling with distinct shapes, not length.** Grader lesson (mine): probe2's
TASK.md omitted the category enum and the session invented a finer valid
taxonomy — contracts must be explicit in task specs, in both directions.

## G. Fail-closed hardening bundle (same day, from Grok adversarial review)

A 12-file Grok refute-mode review (`runs/grok-review-2026-07-12/`, not
published here) found one systemic pattern: **failures coerced into
plausible numbers**. Fixed and test-covered same day (13 new contract tests in
`test_fail_closed.py`; 17 total green):

- Graders (F1/F4): private score-file channel + submission-stdout suppression —
  a submission printing "SCORE 1.0" or os._exit()ing can no longer forge a pass.
- Harness/sweep SCORE parse: returncode==0 + exact last-line fullmatch; grader
  crash → score **null** + grade_error, never 0.0. Lane errors/timeouts → null
  (grading a dead lane's untouched seed scores the SEED, not the model).
- judge.py: transport/parse failure → judge_error flag, not imputed zeros.
- verdict.py: null scores excluded from winner math; judge_error → soft "n/a";
  confidence "n/a" whenever the rig itself failed (no authority w/o evidence).
- spend_logger: unknown cost stays null (completion_cost fallback first);
  gw_spend raises on a missing log and surcharges null-cost records
  ($0.05 default) so budget gates overestimate, never underestimate.
- new_model_watch: flag-order fix (4/4-STRONG was unreachable), infra errors
  defer the model to next week instead of burying it as a permanent zero.

Shared invariant, now the rig's law: **failure is never a number.**
